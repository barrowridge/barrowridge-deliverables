# barrowridge-deliverables

This repo hosts client-facing files for [Barrowridge Solutions](https://barrowridge.com) as password-protected downloads.

**Public visibility here is intentional and only affects access, not confidentiality.** Every file is encrypted (AES) before it's ever committed. Public repo = no login required to download; the password (sent separately, in the delivery email) is the actual access control.

Files are committed directly to the repository tree and delivered as `raw.githubusercontent.com/{owner}/{repo}/{commit-sha}/{path}` permalinks — not GitHub Release assets. (Earlier plan called for Release assets; corrected once it became clear the available tooling can only list/get releases, not create them or upload assets.) If you've found this repo without a password and a specific delivery link, there's nothing here for you to open.
