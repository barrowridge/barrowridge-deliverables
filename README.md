# barrowridge-deliverables

This repo hosts client-facing files for [Barrowridge Solutions](https://barrowridge.com) as password-protected downloads.

**Public visibility here is intentional and only affects access, not confidentiality.** Every file is encrypted (AES) before it's ever committed or attached to a release. Public repo = no login required to download; the password (sent separately, in the delivery email) is the actual access control.

Files are delivered as [Release](../../releases) assets, not committed to the repository tree. If you've found this repo without a password and a specific release link, there's nothing here for you to open.
